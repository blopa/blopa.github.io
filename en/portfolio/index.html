    Musclog

    2024 to today

    An offline-first workout and nutrition tracker. No servers, no account, no subscription. It's my main open-source product, on Google Play and on the web from the same codebase.

    • React Native and Expo Router, with WatermelonDB on top of SQLite on Android and LokiJS on the web.
    • Real food databases (USDA and Open Food Facts), barcode scanning, and OCR for nutrition labels.
    • Weight, body fat and nutrition encrypted at rest, with a key that never leaves the device.
    • Ported to a real Game Boy Color cartridge in C with GBDK-2020: no floats, no malloc, 517 foods packed into ROM banks.
    • Counts barbell reps from a €20 Bluetooth sensor with a random forest exported to plain JavaScript, published as a work in progress.
    • React Native
    • Expo
    • TypeScript
    • WatermelonDB
    • SQLite
    • C

    Resume Builder

    2018 to today

    Builds a resume from a spreadsheet or from a form generated out of the JSON Resume schema. A recruiter found the repo, asked if I knew React, and that's how I ended up in the Netherlands.

    • The form is generated recursively from the JSON Schema, so a schema change needs no code change.
    • Download links are base64 data URIs, so exporting needs no server.
    • Still the tool I use for my own resume, years later.
    • React

    • Material UI

    Super Ollie vs Pebble Corp

    2020 to 2021

    A Phaser 3 skate platformer where the villain is a corporation trying to ban skateboarding. It's not finished, but every step of it is documented in 23 public devlogs.

    • Game rules live in Tiled tile and object properties, and colliders, triggers and AI paths are generated from them at runtime.
    • Rewrote the enemy AI from per-frame tile probes to colliders calculated once, because the first version didn't scale.
    • Wrote my own build tooling: sprite atlas generation, tileset extrusion, and a Webpack transform that inlines Tiled tilesets.
    • Ladders, monkey bars, moving platforms, checkpoints, weather, translations and a mobile build with on-screen controls.
    • Phaser 3
    • JavaScript
    • Tiled
    • Webpack
    • Cordova

    3. Studocu

      May 2018 to today

      Full-stack developer · Amsterdam, Netherlands

      A study platform used by students all over the world. I joined as the 5th developer and stayed while it grew into a much bigger engineering team.

      • My first task was migrating the frontend from CoffeeScript to JSX. Later it went to TypeScript and React 18, and I was the one willing to touch the Webpack config.
      • Moved pages from the Laravel monolith into Next.js one by one, with gradual cookie-based releases and a way back to Laravel if something broke.
      • Made Laravel and Next.js read and write the same encrypted session cookies by reimplementing Laravel's AES-256-CBC and HMAC format with the Web Crypto API.
      • On the engineering on-call rotation since 2022, and migrated error reporting from Bugsnag to Sentry across both apps behind a feature flag.
      • Owned A/B tests end to end: build them, read the results, decide, then delete the losing variant.
      • Ran the frontend guild from 2021 and did technical interviews that helped hire around 10 people.
      • React
      • Next.js
      • TypeScript
      • Laravel
      • PHP
      • Kubernetes
      • Sentry

      On the blog:

    4. Muxi

      2016 to April 2018

      Software developer · Brazil

      Software for payment terminals, in a JavaScript-like language running on a native C runtime. Most of it for Cielo, the company's biggest client.
