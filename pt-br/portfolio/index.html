    Musclog

    2024 até hoje

    Um app de treino e nutrição offline-first. Sem servidor, sem conta, sem assinatura. É o meu principal produto open source, no Google Play e na web a partir do mesmo código.

    • React Native e Expo Router, com WatermelonDB em cima de SQLite no Android e LokiJS na web.
    • Bases de alimentos de verdade (USDA e Open Food Facts), leitor de código de barras e OCR de tabela nutricional.
    • Peso, gordura corporal e nutrição criptografados no aparelho, com uma chave que nunca sai dele.
    • Portado para um cartucho de Game Boy Color de verdade, em C com GBDK-2020: sem float, sem malloc, 517 alimentos empacotados em bancos de ROM.
    • Conta repetições de barra com um sensor Bluetooth de €20 e um random forest exportado para JavaScript puro, publicado como trabalho em andamento.
    • React Native
    • Expo
    • TypeScript
    • WatermelonDB
    • SQLite
    • C

    Resume Builder

    2018 até hoje

    Monta um currículo a partir de uma planilha ou de um formulário gerado a partir do schema do JSON Resume. Um recrutador achou o repositório, perguntou se eu sabia React, e foi assim que eu vim parar na Holanda.

    • O formulário é gerado recursivamente a partir do JSON Schema, então mudar o schema não exige mudar o código.
    • Os links de download são data URIs em base64, então exportar não precisa de servidor.
    • Ainda é a ferramenta que eu uso para o meu próprio currículo, anos depois.
    • React
    • Gatsby
    • Formik
    • JSON Schema
    • Material UI

    Super Ollie vs Pebble Corp

    2020 até 2021

    Um jogo de plataforma de skate em Phaser 3 onde o vilão é uma empresa tentando proibir o skate. Não está terminado, mas cada passo está documentado em 23 devlogs públicos.

    • As regras do jogo ficam nas propriedades dos tiles e objetos do Tiled, e colisores, gatilhos e caminhos da IA são gerados a partir delas em tempo de execução.
    • Reescrevi a IA dos inimigos, trocando checagens de tile a cada frame por colisores calculados uma vez só, porque a primeira versão não escalava.
    • Criei minhas próprias ferramentas de build: geração de sprite atlas, extrusão de tileset e um transform de Webpack que embute os tilesets do Tiled.
    • Escadas, barras para se pendurar, plataformas móveis, checkpoints, clima, traduções e uma versão para celular com controles na tela.
    • Phaser 3
    • JavaScript
    • Tiled
    • Webpack
    • Cordova

    3. Studocu

      maio de 2018 até hoje

      Desenvolvedor full-stack · Amsterdam, Holanda

      Uma plataforma de estudos usada por estudantes do mundo todo. Eu entrei como o 5º desenvolvedor e fiquei enquanto o time de engenharia crescia muito.

      • Minha primeira tarefa foi migrar o frontend de CoffeeScript para JSX. Depois veio TypeScript e React 18, e eu era quem topava mexer na config do Webpack.
      • Migrei páginas do monolito em Laravel para Next.js uma por uma, com releases graduais por cookie e um caminho de volta para o Laravel se algo quebrasse.
      • Fiz o Laravel e o Next.js lerem e escreverem os mesmos cookies de sessão criptografados, reimplementando o formato AES-256-CBC e HMAC do Laravel com a Web Crypto API.
      • No plantão de engenharia desde 2022, e migrei o monitoramento de erros do Bugsnag para o Sentry nos dois apps, atrás de uma feature flag.
      • Fui dono de testes A/B de ponta a ponta: implementar, ler os resultados, decidir e apagar a variante perdedora.
      • Liderei a guilda de frontend a partir de 2021 e fiz entrevistas técnicas que ajudaram a contratar umas 10 pessoas.
      • React
      • Next.js
      • TypeScript
      • Laravel

    5. FingerStore & NanoBoards

      outubro de 2010 até 2020

      Fundador, e todo o resto · Brasil

      • Lancei o primeiro e-commerce de fingerboard do Brasil em Magento 1.4, uns três meses entre a ideia e a loja no ar.
      • Criei a NanoBoards em 2012, minha própria marca, com gráficos licenciados de grandes marcas de skate brasileiras, e exportei para os EUA e a Europa.
      • Tema e módulos próprios de Magento, multi-loja, um configurador de monte-seu-setup e um upgrade de versão por ano durante cinco anos.
      • Aceitei Bitcoin a partir de 2014, muito antes disso ser normal para uma loja pequena.
